# PCG schema authoring

HORO-2048 extends the existing catalog and document contracts without changing graph source 1.1 or cooked-plan bytes.

`PCGNodeCatalogSnapshot::DecodeSettings` projects an authored node into the closed `PCGNodeAuthoringSettings` variant after exact version, pin, capability and payload validation. `EncodeSettings` uses the existing PCG-owned codecs and rejects mismatched alternatives. Editor code never parses opaque payload bytes or depends on target-private runtime headers. The existing public catalog consumer covers the additional API.

`PCGGraphAuthoringDraft` is transient presentation intent. Capture it from a document snapshot and the host's executable catalog, add/remove exposed typed pin bindings, rename their keys, modify typed policy/default/settings values, then prepare `Command` against the current captures and submit that command through the workspace's canonical document executor. It produces one semantic history entry for the entire Apply gesture. Cancel drops the draft without a command. History, source reload, document replacement, catalog replacement and close fence old drafts. No draft changes source, dirty state, history or files directly.

Unknown nodes, malformed settings and unsupported versions retain their exact source payloads with diagnostics. Unsupported generation modes remain visible and disabled in the selector. They are never mapped to Offline or another available mode. A validation-only host may edit other values while retaining an already-authored unsupported mode; changing to a new unsupported mode fails. This authoring surface grants no evaluation or bake capability. Exposed inputs show their typed authored defaults and explain that an external runtime value may override them; this is not a guarantee of deterministic provider data. Numeric editing preserves full-width seeds and round-trip floating values and rejects non-finite/intermediate invalid text before Apply. Generation count and strata products respect the graph's operational tier before a command is emitted. Spatial identities are explicit authored references; the inspector does not fabricate provider availability or evaluate a graph.

The workspace owns inspector buffers and drafts. Panel detach releases them, and session/revision refresh replaces a pending draft before the next draw; they are never persisted in `.hpcg` or copied into a runtime plan. Shared editor controls resolve active theme tokens, localized English/Turkish labels, keyboard focus and disabled states. Visual/device checks and hosted build/test/quality checks remain separate evidence from source review.
