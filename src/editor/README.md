# Editor

Owns editor documents, screens, authoring tools and editor-only runtime adapters.

Start at [`screens/`](screens/) for screen and workspace flows, [`document/`](document/) for editable Scene state, [`design_system/`](design_system/) for shared controls, or [`renderer/`](renderer/) for viewport composition. XR authoring tools are in [`xr/`](xr/) and runtime XR is in [the XR module](../runtime/xr/README.md).
