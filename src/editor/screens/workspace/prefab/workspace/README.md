# Prefab workspace commands

[EditorWorkspaceControllerPrefabDocuments.cpp](EditorWorkspaceControllerPrefabDocuments.cpp)
routes open prefab document commands. The other handlers cover prefab settings and applying
prefab operations in the workspace. See [document sessions](../document/README.md) for persistence,
[asset helpers](../assets/README.md) for creation and apply, and [hierarchy](../hierarchy/README.md)
for object projection.
