# Terrain brush producers

The sculpt, paint, and foliage producers turn a brush gesture into typed edit input.
Start with [TerrainSculptProducer.cpp](TerrainSculptProducer.cpp) for height edits or
[FoliagePaintProducer.cpp](FoliagePaintProducer.cpp) for foliage placement.
The [terrain document](../document/README.md) owns publication of accepted edits.
