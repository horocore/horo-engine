# Foliage palette and selection

[FoliagePaletteModel.cpp](FoliagePaletteModel.cpp) builds the palette entries and
[FoliagePaletteTab.cpp](FoliagePaletteTab.cpp) presents them.
[FoliageSelectionModel.cpp](FoliageSelectionModel.cpp) tracks the selected foliage entry for
the [brush producers](../brushes/README.md).
