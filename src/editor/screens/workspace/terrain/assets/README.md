# Terrain asset creation

[TerrainAssetCreationModal.cpp](TerrainAssetCreationModal.cpp) presents the new terrain asset
workflow. [TerrainAssetCreation.h](TerrainAssetCreation.h) exposes its creation request, and
[TerrainAssetFormat.cpp](TerrainAssetFormat.cpp) handles the workspace asset representation.
The [document host](../document/README.md) manages the opened asset.
