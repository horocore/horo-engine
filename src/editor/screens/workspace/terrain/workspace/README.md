# Terrain workspace commands

[EditorWorkspaceControllerTerrain.cpp](EditorWorkspaceControllerTerrain.cpp) coordinates
terrain documents. Additional handlers cover asset creation, cooking, and tool commands.
[EditorWorkspaceScreenTerrain.cpp](EditorWorkspaceScreenTerrain.cpp) and
[EditorWorkspaceViewTerrain.cpp](EditorWorkspaceViewTerrain.cpp) connect the
[terrain document and tool helpers](../) to the screen.
