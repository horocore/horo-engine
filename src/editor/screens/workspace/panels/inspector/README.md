# Workspace inspector

[InspectorPanel.cpp](InspectorPanel.cpp) coordinates selected-object presentation and
submits edits through its attached workspace host. [Edit sessions](edits/README.md) hold temporary
input. [Component definitions](add_component/README.md) drive the creation menu, and
[component fields](component_fields/README.md) describe existing properties.

- [Physics](physics/README.md) and [navigation](navigation/README.md) handle typed authoring controls.
- [UI canvas](ui_canvas/README.md) presents canvas controls and authoring fields.
- [Contributions](contributions/README.md) displays admitted extension projections.
