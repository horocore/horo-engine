# Prefab hierarchy presentation

The prefab-specific hierarchy adapters use the [panel](../README.md) lifecycle.
[HierarchyPrefabRows.cpp](HierarchyPrefabRows.cpp) renders the projected rows,
[HierarchyPrefabContext.cpp](HierarchyPrefabContext.cpp) presents row actions, and
[HierarchyPrefabDragDrop.cpp](HierarchyPrefabDragDrop.cpp) routes supported drag and drop gestures.
