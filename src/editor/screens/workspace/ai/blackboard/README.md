# Blackboard authoring

[EditorWorkspaceControllerBlackboard.cpp](EditorWorkspaceControllerBlackboard.cpp) handles
blackboard document commands. [EditorWorkspaceViewBlackboard.cpp](EditorWorkspaceViewBlackboard.cpp)
draws the projected keys and values using the local editor widgets.
[EditorWorkspaceBlackboardRecovery.cpp](EditorWorkspaceBlackboardRecovery.cpp) handles recovery.
