# Scene inspection and debug capture

[EditorWorkspaceControllerSceneProjection.cpp](EditorWorkspaceControllerSceneProjection.cpp)
builds scene and viewport projections and supplies revision-bound agent inspection.
[EditorWorkspaceControllerDebugCapture.cpp](EditorWorkspaceControllerDebugCapture.cpp) handles
debug captures. The [command boundary](../commands/README.md) exposes admitted operations.
