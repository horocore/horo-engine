# Workspace extension contributions

[EditorWorkspaceControllerInspectorContributions.cpp](EditorWorkspaceControllerInspectorContributions.cpp)
projects extension contributions into the inspector. The approval handler and
[InspectorExtensionEdit.h](InspectorExtensionEdit.h) keep edits within the workspace command boundary.
[ExtensionRecoveryView.cpp](ExtensionRecoveryView.cpp) presents recovery information.
See [activity](activity/README.md) for the activity view.
