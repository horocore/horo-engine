# Workspace docking

[WorkspacePanelRegistry.cpp](WorkspacePanelRegistry.cpp) resolves registered panel definitions,
and [WorkspacePanelHost.cpp](WorkspacePanelHost.cpp) presents the active panels.
[DefaultWorkspacePanels.cpp](DefaultWorkspacePanels.cpp) registers built-in panels.
The [layout module](../layout/README.md) handles geometry and persistence.
