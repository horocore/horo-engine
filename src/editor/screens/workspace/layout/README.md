# Workspace layout

[WorkspaceLayout.cpp](WorkspaceLayout.cpp) computes the workspace layout.
[WorkspaceLayoutPersistence.cpp](WorkspaceLayoutPersistence.cpp) and
[WorkspaceLayoutFileStore.cpp](WorkspaceLayoutFileStore.cpp) handle saved layouts and storage.
The activity bar and splitter helpers handle local geometry and interaction.
[Docking](../docking/README.md) owns the panel host and registry.
