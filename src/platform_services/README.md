# Platform services

Owns typed platform-service requests, provider coordination and offline work for achievements, friends, presence, leaderboards and cloud data.

Look for the feature-named coordinators, such as [`PlatformAchievementCoordinator.cpp`](PlatformAchievementCoordinator.cpp), or for queueing in the `PlatformOfflineQueue` files.
