# Foundation

Owns shared engine primitives such as errors, jobs, time, paths and module metadata.

Start at [`jobs/`](jobs/) for task execution, [`error/`](error/) for error transport, [`paths/`](paths/) for path handling and [`modules/`](modules/) for module metadata. Application composition assembles these services for each host.
