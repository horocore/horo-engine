# Destruction runtime

Owns fracture data and the runtime state transitions for breakable objects, with separate cook, save and network adapters.

- [`cook/`](cook/) — Fracture artifact production.
- [`runtime/`](runtime/) — Destruction state and runtime operations.
- [`network/`](network/) — Replication adapters.
- [`save/`](save/) — Persistent state adapters.
