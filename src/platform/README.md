# Platform

Owns OS-level services such as storage, processes, windows and native device access.

Start at [`desktop/`](desktop/) and [`android/`](android/) for platform hosts, [`file_storage/`](file_storage/) for filesystem operations and [`windows/`](windows/) or [`posix/`](posix/) for OS-specific implementations.
