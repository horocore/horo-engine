# Scene physics publication

Scene structural changes, cell and tile attachment, physical surface projection, and character snapshot integration.

Start with [PhysicsSceneStructural.cpp](PhysicsSceneStructural.cpp) for live structural edits and
[PhysicsCellAttachments.cpp](PhysicsCellAttachments.cpp) for streamed cell collision. Use
[PhysicsSceneSurfaceProjection.cpp](PhysicsSceneSurfaceProjection.cpp) to trace material binding and
[PhysicsStaticTileAdmission.cpp](PhysicsStaticTileAdmission.cpp) to trace the producer and tile lifecycle.
