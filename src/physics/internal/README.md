# Private physics integration

These non-installed contracts let the Scene host work with its paired Physics and Character owners.
[PhysicsSceneHostAccess.h](PhysicsSceneHostAccess.h) provides access to the active pair on the owner lane.
[CharacterScenePlacement.h](CharacterScenePlacement.h) covers initial placement and
[CharacterSceneFixedAccess.h](CharacterSceneFixedAccess.h) covers staging and publishing fixed-tick movement.
