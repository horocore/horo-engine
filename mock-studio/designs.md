# Mock Studio design index

Run `npm ci` and `npm run dev` in `mock-studio/`, then select a design from the catalog.
The IDs below retain their former `.html` suffix so existing design deep links remain stable; no HTML document is loaded.
Each screen is a React component backed by checked-in design data.
